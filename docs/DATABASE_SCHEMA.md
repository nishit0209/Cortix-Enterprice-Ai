# Database Schema

> Status: **Design.** Last updated 2026-11-17. Diagrams: `DATABASE_ERD.md`. Tenancy mechanics: `MULTI_TENANCY_DESIGN.md`.
> The DDL below is **normative pseudo-DDL**: Django models and migrations must produce equivalent structures. `T` marks a tenant table that gets the canonical RLS policy.

## 1. Databases, schemas and roles

| Database | Contents | Isolation model |
|---|---|---|
| `nexora_app` | All platform metadata, audit, AI logs, vectors (pgvector) | Shared tables, `org_id` column, **RLS (FORCE)** |
| `nexora_wh` | Ingested analytical tables (immutable dataset versions) | **Schema per org** (`org_<short_id>`), one reader role per org |

| Role | Login | Purpose | Key privileges |
|---|---|---|---|
| `nexora_owner` | NOLOGIN | Owns all `nexora_app` objects | Owner (RLS is still enforced through `FORCE ROW LEVEL SECURITY`) |
| `nexora_migrator` | LOGIN | Runs `manage.py migrate` only (`DJANGO_DB_ROLE=migrator`) | Member of `nexora_owner` |
| `nexora_app` | LOGIN | API and workers | DML on tenant tables, `NOBYPASSRLS`; INSERT and SELECT only on append-only tables |
| `nexora_ops` | LOGIN | Beat dispatcher, retention, platform aggregates, super-admin read APIs | `BYPASSRLS`; used only through the `ops` DB alias in `platform_admin`/`core.ops` modules |
| `wh_loader` | LOGIN | Creates per-org schemas and tables in `nexora_wh`, loads data with `COPY` | Owns `org_*` schemas |
| `wh_q_<short_id>` | LOGIN (one per org) | Guarded NL→SQL execution on that org's data | `USAGE` on its own schema, `SELECT` on its tables; `default_transaction_read_only=on`, `statement_timeout=20s`, `temp_file_limit=256MB`, `CONNECTION LIMIT 4`; no `CREATE`/`TEMP` |

`PUBLIC` loses `CREATE` on all schemas and `TEMP` on `nexora_wh`. The `public` schema in `nexora_wh` is empty and locked.

## 2. Conventions

- **Primary keys:** `id uuid`, generated by the app as UUIDv7 (PostgreSQL 17 has no native v7).
- **Tenant columns:** every `T` table has `org_id uuid NOT NULL REFERENCES organization(id) ON DELETE RESTRICT`. Org deletion is a soft delete followed by a purge job (see §12).
- **Timestamps:** `created_at timestamptz NOT NULL DEFAULT now()` and `updated_at timestamptz NOT NULL DEFAULT now()` on mutable tables; `created_by uuid NULL REFERENCES "user"(id)`.
- **Enums:** `text` with `CHECK (... IN (...))` rather than PG enum types, so migrations stay easier.
- **Indexes:** every `T` table has an index whose leading column is `org_id`. Every FK is indexed. Every `UNIQUE` constraint on a `T` table includes `org_id`.
- **Partitioning:** high-volume logs are `PARTITION BY RANGE (occurred_at|created_at)` monthly. Partitions are created ahead by a beat task, and old partitions are dropped by retention policy.
- **Append-only tables** (`audit_event`, `bi_query_audit`, `ai_policy_consent`, `access_history`, `ai_request_log`): `nexora_app` has only `INSERT, SELECT`, and a trigger `forbid_mutation()` raises on `UPDATE`/`DELETE`. Retention drops whole partitions as `nexora_ops`.
- **Canonical RLS policy** (emitted by the `EnableTenantRLS` migration operation, using the single tenant setting `app.org_id`):

```sql
ALTER TABLE <t> ENABLE ROW LEVEL SECURITY;
ALTER TABLE <t> FORCE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON <t>
  USING      (org_id = NULLIF(current_setting('app.org_id', true), '')::uuid)
  WITH CHECK (org_id = NULLIF(current_setting('app.org_id', true), '')::uuid);
```

- **Global tables** (no `org_id`): `"user"`, `permission`, `ai_prompt_template`, `ai_model_quota`, `platform_audit_event`, `platform_health_snapshot`, Django and django-otp internals, django-celery-beat. `organization` is global but has a self-policy (§3).

### 2.1 Pre-tenant lookups (security-definer functions)
Some lookups must happen **before** a tenant context exists. Each is a narrow `SECURITY DEFINER` function owned by `nexora_owner`, with `SET search_path = pg_catalog, public`, and `EXECUTE` granted to `nexora_app`:

| Function | Returns | Used by |
|---|---|---|
| `nexora_user_orgs(p_user uuid)` | `(org_id, slug, name, role_key, status)` for the user's active memberships | Org switcher, login redirect |
| `nexora_membership_check(p_user uuid, p_org_slug text)` | `(org_id, role_id)` or nothing | `TenantAPIView.initial()` |
| `nexora_invitation_by_token(p_token_hash bytea)` | `(invitation_id, org_id, email, role_id, expires_at)` if valid | Accept-invitation flow |
| `nexora_api_key_lookup(p_prefix text)` | `(api_key_id, org_id, key_hash, scopes, expires_at, revoked_at)` | API-key authentication |

No other code path reads across tenants, except the `nexora_ops` alias in platform modules.

```sql
CREATE TABLE organization (

CREATE TABLE api_key (                               -- T

  prefix char(8) NOT NULL UNIQUE, key_hash bytea NOT NULL,   -- argon2/sha256-hmac of the secret part
  scopes text[] NOT NULL,                            -- e.g. {'ml.predict','datasets.read'}

CREATE TABLE ai_policy_consent (                     -- T, append-only

-- Valid consent = latest row for (org_id, policy) has action='grant' and consent_text_version = current version.
```

## 4. Audit and governance (Phases 2 and 5): `core`, `governance`

```sql
CREATE TABLE audit_event (                           -- T, append-only, PARTITION BY RANGE (occurred_at) monthly
  id uuid NOT NULL, org_id uuid NOT NULL, occurred_at timestamptz NOT NULL DEFAULT now(),
  actor_type text NOT NULL CHECK (actor_type IN ('user','api_key','system','agent')),
  actor_id uuid, action text NOT NULL,               -- 'dataset.create', 'policy.update', 'ai.consent.grant', ...
  target_type text, target_id uuid,
  request_id text, ip inet, user_agent text,
  changes jsonb,                                     -- redacted before/after diff
  metadata jsonb NOT NULL DEFAULT '{}',
  seq bigint, prev_hash bytea, hash bytea,           -- filled by the sealing job (per-org chain)
  PRIMARY KEY (id, occurred_at)
);
CREATE INDEX ON audit_event (org_id, occurred_at DESC);
CREATE INDEX ON audit_event (org_id, target_type, target_id);
```

**Hash chain:** a beat job (`core.audit.seal`, every minute, as `nexora_ops`) assigns a per-org `seq` and computes `hash = sha256(prev_hash || canonical_json(row))` in `(occurred_at, id)` order. Sealing is the only UPDATE path, and the trigger allows it only for `nexora_ops` and only on null `seq/hash` columns. `GET /audit-events/verify` recomputes the chain.

```sql
CREATE TABLE platform_audit_event (LIKE audit_event INCLUDING DEFAULTS);   -- global (org_id nullable), super-admin actions
```

## 5. Data Engineering (Phase 3): `connectors`, `datasets`, `pipelines`, `quality`, `lineage`, `warehouse`

```sql
CREATE TABLE credential (                            -- T; never serialized by any API
  id uuid PRIMARY KEY, org_id uuid NOT NULL,
  kind text NOT NULL CHECK (kind IN ('db_password','api_token','oauth_refresh','gemini_api_key')),
  ciphertext bytea NOT NULL, nonce bytea NOT NULL,   -- AES-256-GCM
  wrapped_dek bytea NOT NULL, kek_id text NOT NULL,  -- envelope encryption; KEK from env/KMS
  aad text NOT NULL,                                 -- 'org:<id>:credential:<id>' bound as AAD
  created_at timestamptz NOT NULL DEFAULT now(), rotated_at timestamptz
);

CREATE TABLE data_source (                           -- T
  id uuid PRIMARY KEY, org_id uuid NOT NULL, name text NOT NULL,
  type text NOT NULL CHECK (type IN ('csv','excel','json','postgresql','mysql','rest')),
  config jsonb NOT NULL DEFAULT '{}',                -- non-secret: host, port, dbname, sslmode, schema/table allowlist, REST base URL…
  credential_id uuid REFERENCES credential(id),
  status text NOT NULL DEFAULT 'active' CHECK (status IN ('active','error','disabled')),
  verified_readonly boolean NOT NULL DEFAULT false,  -- external DBs: privilege check passed
  resolved_ip inet,                                  -- SSRF pinning (external DBs)
  last_tested_at timestamptz, last_test_result jsonb,
  created_by uuid, created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (org_id, name)
);

CREATE TABLE upload (                                -- T
  id uuid PRIMARY KEY, org_id uuid NOT NULL, filename text NOT NULL, content_type text NOT NULL,
  size_bytes bigint NOT NULL, sha256 bytea NOT NULL, object_key text NOT NULL,   -- orgs/<org>/uploads/<id>
  status text NOT NULL DEFAULT 'uploaded' CHECK (status IN ('uploaded','scanning','ready','rejected')),
  reject_reason text, created_by uuid NOT NULL, created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE dataset (                               -- T
  id uuid PRIMARY KEY, org_id uuid NOT NULL, name text NOT NULL, slug text NOT NULL, description text NOT NULL DEFAULT '',
  source_kind text NOT NULL CHECK (source_kind IN ('upload','connector','pipeline')),
  data_source_id uuid REFERENCES data_source(id),
  classification text NOT NULL DEFAULT 'internal'
      CHECK (classification IN ('synthetic','public','internal','confidential')),
  classification_attested_by uuid, classification_attested_at timestamptz,   -- required for synthetic/public
  owner_id uuid NOT NULL, current_version_id uuid,   -- FK added after dataset_version
  status text NOT NULL DEFAULT 'active' CHECK (status IN ('active','archived','deleted')),
  tags text[] NOT NULL DEFAULT '{}',
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (org_id, slug)
);

CREATE TABLE dataset_version (                       -- T; one immutable table in nexora_wh
  id uuid PRIMARY KEY, org_id uuid NOT NULL, dataset_id uuid NOT NULL REFERENCES dataset(id),
  version integer NOT NULL, wh_schema text NOT NULL, wh_table text NOT NULL,  -- org_ab12cd34 . ds_<short>_v<n>
  row_count bigint, byte_size bigint, schema_hash bytea NOT NULL,
  created_by_run_id uuid, upload_id uuid REFERENCES upload(id),
  profile jsonb,                                     -- summary; per-column stats in dataset_column
  status text NOT NULL DEFAULT 'loading' CHECK (status IN ('loading','ready','failed','retired')),
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (dataset_id, version)
);

CREATE TABLE dataset_column (                        -- T
  id uuid PRIMARY KEY, org_id uuid NOT NULL, dataset_version_id uuid NOT NULL REFERENCES dataset_version(id) ON DELETE CASCADE,
  ordinal integer NOT NULL, name text NOT NULL, source_name text NOT NULL,
  data_type text NOT NULL,                           -- bigint|double precision|numeric|text|boolean|date|timestamptz|jsonb
  semantic_type text,                                -- id|email|phone|currency|percent|date|category|free_text|geo_country|geo_city|url|...
  nullable boolean NOT NULL, is_pii boolean NOT NULL DEFAULT false,
  stats jsonb NOT NULL DEFAULT '{}',                 -- null_pct, distinct, min, max, mean, p50, top_values (suppressed for PII)
  UNIQUE (dataset_version_id, name)
);

CREATE TABLE pipeline (                              -- T
  id uuid PRIMARY KEY, org_id uuid NOT NULL, name text NOT NULL, description text NOT NULL DEFAULT '',
  owner_id uuid NOT NULL, current_version_id uuid,
  status text NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','active','paused','archived')),
  max_attempts smallint NOT NULL DEFAULT 3, retry_backoff_s integer NOT NULL DEFAULT 60,
  notify_on_failure boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (org_id, name)
);

CREATE TABLE pipeline_version (                      -- T; immutable once published
  id uuid PRIMARY KEY, org_id uuid NOT NULL, pipeline_id uuid NOT NULL REFERENCES pipeline(id),
  version integer NOT NULL, dag jsonb NOT NULL,      -- see DATA_ENGINEERING_DESIGN.md §5 (validated JSON Schema)
```

**Org deletion:**
1. `organization.status='deleted'` and `deleted_at` is set. Members lose access immediately.
2. After a grace period (default 30 days), `core.ops.purge_org` running as `nexora_ops`:
   - drops `org_<short_id>` and the `wh_q_*` role;
   - deletes objects under `orgs/{id}/`;
   - deletes tenant rows in FK order;
   - keeps the `audit_event` partitions until their retention ends.

## 13. Migration ownership and order

- Each Django app's migrations are owned by that app's agent (`coordination/OWNERSHIP.md`).
- `core` provides the `EnableTenantRLS`, `CreateAppendOnlyTrigger` and `CreateMonthlyPartitions` operations.
- Bootstrap SQL (roles, extensions `vector` and `citext`, the security-definer functions) lives in `infra/postgres/init/*.sql`, owned by the Integrator, and runs before migrations.
- Cross-app FK order follows the layering in `SYSTEM_ARCHITECTURE.md` §3.1.
